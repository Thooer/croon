# Tree

Tree 是提供者一侧共用的内容格式，Kernel 不解释它。它是 Bundle 的一种用法，不是 Kernel 的机制。

Tree 是目录 Bundle：内容为名字到条目的映射。在 croon-tree 的头里写的是使用方必须守什么；这里只说为什么是这样。

一个目录的内容完全由它的名字与字节决定，所以直接依赖就可以恰好等于 file、dir 指向的那些 Bundle：多出来的依赖要么是多余的，要么是拿不到的内容，两种情况都该在装入时失败，而不是留到读取时才发现。所以排序去重、不多不少都是同一个判断的两面。

link 是目标字符串而不是一个 Bundle：它指的东西可能在 Tree 之外，也不由这份内容决定，所以它既不引入依赖，也不跟随。跟随是使用方在某个宿主上做的决定，那一步会受宿主的限制，不是形状能管的。

形状与磁盘分开：Tree 由内容与依赖决定，校验只看这两样。目录怎样遍历、符号链接跟不跟、可执行位怎么记、路径穿越怎么拒绝，取决于宿主与调用方，不改变 Tree 是什么。所以 `croon-tree` 不碰文件系统。

形状是 `directory.tree`。
